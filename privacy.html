Política de Privacidade — VIRAL LAB

Última atualização: 20/11/2026

1. O que é

O VIRAL LAB é uma ferramenta de uso pessoal que roda no próprio computador do usuário (banco de dados local). Não há servidor do VIRAL LAB que receba ou armazene dados de usuários.

2. Quais dados do TikTok são acessados

Somente depois que o próprio usuário autoriza (Login Kit), e somente os escopos user.info.basic (nome de exibição e identificador da conta) e video.list (lista dos vídeos públicos da conta e suas contagens de visualizações, curtidas, comentários e compartilhamentos). O app acessa apenas os vídeos da conta que o usuário autorizou. Não acessa mensagens, contatos, vídeos privados nem dados de outras pessoas.

3. Para que são usados

Exclusivamente para mostrar ao próprio usuário o desempenho dos seus vídeos e comparar versões de conteúdo. Os dados não são vendidos, compartilhados, usados para publicidade ou para treinar modelos.

4. Onde ficam e por quanto tempo

Os dados e os tokens de acesso ficam apenas no computador do usuário, no banco local; os tokens são armazenados cifrados. Permanecem até o usuário desconectar a conta ou apagar os dados.

5. Como revogar e apagar

O usuário pode desconectar a conta a qualquer momento no próprio VIRAL LAB (Configurações → TikTok → Desconectar), o que apaga os tokens, e pode revogar o acesso no TikTok em Configurações e privacidade → Segurança → Apps e serviços. Os dados já importados podem ser apagados pelo usuário no VIRAL LAB.

6. Crianças

O serviço não é direcionado a menores de 13 anos.

7. Mudanças

Esta política pode ser atualizada; a data no topo indica a versão vigente.

Privacy Policy — VIRAL LAB

Last updated: 2026-11-20

What it is. VIRAL LAB is a personal tool that runs on the user's own computer (local database). There is no VIRAL LAB server that receives or stores user data.

TikTok data accessed. Only after the user authorizes it through Login Kit, and only the scopes user.info.basic (display name and account identifier) and video.list (the account's public videos and their view, like, comment and share counts). The app reads only the videos of the account the user authorized. It does not access messages, contacts, private videos or other people's data.

Use. Solely to show the user the performance of their own videos and compare content versions. Data is not sold, shared, used for advertising or to train models.

Storage and retention. Data and access tokens stay only on the user's computer in a local database; tokens are stored encrypted. They remain until the user disconnects the account or deletes the data.

Revocation and deletion. The user can disconnect the account at any time in VIRAL LAB (Settings → TikTok → Disconnect), which deletes the tokens, and can revoke access in TikTok under Settings and privacy → Security → Apps and services. Already imported data can be deleted by the user inside VIRAL LAB.

Children. The service is not directed to children under 13.

Changes. This policy may be updated; the date above shows the current version.
